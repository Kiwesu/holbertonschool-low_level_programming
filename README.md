# Holberton School - Low Level Programming

## Learning Objectives

- Why C is awesome and who invented it (Dennis Ritchie, Brian Kernighan, Linus Torvalds).
- What happens when you run `gcc main.c`.
- What is an entry point and `main` function.
- How to print text (`printf`, `puts`, `putchar`).
- How to use `sizeof` to get data type sizes.
- How to compile with `gcc` and default executable name.
- Follow official C coding style checked by Betty.
- How to find proper headers for standard functions.
- Understand how `main` return value affects the program.

## Requirements

### C Programs

- Use `vi`, `vim`, or `emacs`.
- Compile on Ubuntu 20.04 LTS with `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- Files must end with a newline.
- Add `README.md` describing repo and project.
- No compile errors or warnings allowed.
- Do not use `system()`.
- Follow Betty style (checked with `betty-style.pl` and `betty-doc.pl`).

### Shell Scripts

- Use `vi`, `vim`, or `emacs`.
- Tested on Ubuntu 20.04 LTS.
- Scripts must be exactly 2 lines.
- Files must end with a newline.
- First line must be `#!/bin/bash`.
